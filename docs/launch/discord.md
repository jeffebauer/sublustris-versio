## Where and how

- **Channel:** the server's showcase or firmware channel, wherever third-party Versio firmware gets shared. Check the channel's pinned rules first, since some servers keep third-party releases to one channel.
- **Format:** Discord Markdown. Bare links unfurl into previews, so wrap all but the site in `< >` to keep the message to one preview card. The site's preview card shows the render already, so no attachment is needed. If you'd rather attach one, use `docs/minisite/assets/renders/front-on-wide.jpg`.
- **Tone:** it's NE's own server, so the not-affiliated line stays in.

## Message

```
Hi all! I've just put out Sublustris Versio, a free reverb firmware for the Versio and a sibling to Resilio. It's a big, dark space for ambient and dub techno. Turn DECAY past 3 o'clock and it holds the chord you stopped on, notes and all. Tap the button to freeze, and hold it while frozen to paint into the pad. MOTION goes from a tired cassette on the left to an old AM radio on the right.

It installs with the Firmware Swap app and goes back to stock the same way. There's an AU/VST3 version for macOS too, if you want to hear it first.

Demos and downloads: https://sublustris-versio.vercel.app
Install guide: <https://sublustris-versio.vercel.app/install/>
Source: <https://github.com/jeffebauer/sublustris-versio>

Independent project, not affiliated with or endorsed by NE (thanks for keeping the Versio open!). Feedback very welcome, here or on GitHub.
```
